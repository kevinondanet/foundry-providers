# Port notes: inspect_ai subsystems in InspectAzureAI

One note per ported subsystem. Each note records what was ported and from which Python files, the public C# API, every deviation from the Python behaviour and why, and what was left out. This index gives one line per note; the deviation column is the short form, the note has the full list. `docs/ARCHITECTURE.md` section 4 explains how the subsystems fit together at runtime.

Python source paths are relative to `src/inspect_ai/`; C# paths to `src/InspectAzureAI.Eval/` unless another project is named.
